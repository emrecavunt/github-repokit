# github-repokit plugin

Agent plugin for [GitHub RepoKit](https://github.com/emrecavunt/github-repokit):
per-repo GitHub governance as Terragrunt, plus optional AWS OIDC and GCP WIF.

Install: see [plugins/README.md](../README.md). Skills live in `skills/`.
Apply is human-gated. This plugin does not write workflow YAML.
